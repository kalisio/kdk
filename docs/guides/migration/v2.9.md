# v2.9 - September 2026

More details can be found in the related [milestone](https://github.com/kalisio/kdk/milestone/17) on GitHub.

## Major breaking changes

💥 `isExpanded` property renamed `expanded` in `KTextArea`.

## Major new features

👉 `v-safe-html` directive to be used to avoid XSS in your apps.

👉 Geotiff grid source now supports web mercator projection.

👉 Improved tiled mesh layer rendering.

👉 `KTextArea` content has now a `copyable` property.

👉 Actions to quickly activate/deactive all filters of a layer in `KFilteredLayerItem` component.
